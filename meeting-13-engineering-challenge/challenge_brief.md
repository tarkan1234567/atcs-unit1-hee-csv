# Algorithm Engineering Challenge
Select and defend an appropriate **data structure + algorithm** for an unfamiliar computational problem.

## Required Evidence
- Problem definition and acceptance criteria
- Data characteristics
- Candidate structures and algorithms
- Selection rationale
- Correct implementation and tests
- Benchmark methodology/results
- Complexity analysis
- PR/review evidence
- Technical-defense preparation

Python is the default. Java or C++ may be used when language/library choice is itself part of a defensible engineering decision.
