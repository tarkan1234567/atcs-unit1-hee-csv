# ATCS Unit 1 - Algorithms, Data Structures & Computational Thinking

Starter/template repository for **Advanced Topics in Computer Science (ATCS) Unit 1**.

## Driving Question
**How do we organize data and choose algorithms to solve problems efficiently?**

Create a private repository from this template and use it throughout Unit 1. Meetings 1-2 are workbook/discussion experiences; coding resources begin with Meeting 3.

## Professional Workflow
Issue -> Acceptance Criteria -> Feature Branch -> Develop/Test -> Meaningful Commits -> Push -> Pull Request -> Review -> Merge

Do not develop directly on `main`.

## Language Strategy
- **Python:** primary implementation and benchmarking language
- **Java:** ADTs, interfaces, and collection-framework lens
- **C++:** containers, representation, and performance lens

The goal is to recognize the computer-science abstraction underneath language-specific syntax.
